1. Your past forecasts and what really happened

What this is. Calibra learns how wrong your forecaster has been, then puts an honest 90% range around each new forecast. For that it needs two CSV files from your system. Column names can be anything; you tell Calibra which is which in step 2.

File 1: Forecasts. One row per forecast.

  • When it is for: start time of the period forecast, e.g. 2025-03-14 17:00
  • When it was made: must be before the start time
  • The forecast number: one number per row
  • Optional: your own low and high, the kind of day, inputs such as temperature

File 2: Actual results. One row per period that has ended.

  • When it is for: the same start time as in file 1
  • The actual number: what really happened

More history gives a better range. Calibra needs at least 20 results for a kind of day to give it its own range. If a time is missing or the files do not line up, the import stops with a message and nothing is saved.
